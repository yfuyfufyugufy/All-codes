### Console Cheats
Go to Blooket_cheats and click either "Blooket set points (Console))" or "Cheats Menu (Console)" then on blooket left click and press inspect. Click Console in the top, then paste in the code, if it does not let you paste it in then type "allow pasting" and paste it in.
